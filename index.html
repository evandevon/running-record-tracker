Use a dedicated folder inside your OneDrive, for example Reading Samples. You can make one with the New folder button in the window that opens. Don't choose your whole OneDrive.

Connected: none
What this tool does and doesn't do
It does
  • Read and write only inside the one folder you choose.
  • Run entirely on this computer, in your browser.
  • Rely on your own OneDrive to back up that folder, as it does for any file you save.
It doesn't
  • See any other folders or files on this computer or in your OneDrive.
  • Send recordings or student details anywhere. The page blocks itself from the internet.
  • Use accounts, sign-ins, tracking, analytics or a server.
How to check this yourself
  1. Offline test: once this page has loaded, turn off Wi-Fi. Everything keeps working.
  2. Network check (for IT): press F12, open the Network tab, and use the tool. No requests are made after the page loads.
  3. Read the code: this is one file with no outside libraries. The source is public on GitHub, and the version number at the top matches a GitHub release.
  4. See or remove access: while connected, a folder icon appears in the address bar. Click it, or go to Site settings, to see which folder this site can use or to remove access.
